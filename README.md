# Urge Button

Press it when an urge hits. The screen locks for a few minutes, you pick something better to do (walk, music, Sudoku, text a friend), and every urge is tracked so you can see the trend.

- **PC (Windows):** `pythonw urge_button.py` - floating button, Ctrl+Alt+U, full-screen lock, progress charts. Tests: `python -m pytest tests`.
- **Phone:** https://perryindustries.github.io/urge-button/ - add it to your home screen. Built from `phone/urge-button.html` by `phone/build_pwa.py` into `docs/`.
